# Instalar PRO Secure v8

1. Descomprime el ZIP completo.
2. En GitHub abre `Miguelma1969/-marin-fotografia-video`.
3. Sube los archivos y carpetas internos reemplazando la versión anterior.
4. Commit: `Actualizar Marin Fotografia PRO Secure v8`.
5. Render desplegará automáticamente.
6. Confirma `Your service is live`.
7. Actualiza la página con `Ctrl + Shift + R`.

## Variables nuevas opcionales para SMS

Consulta `CONFIGURAR_SMS_TWILIO.md`.

Las funciones de fotos, Zelle y email continúan funcionando aunque Twilio todavía no esté configurado. En ese caso, Render mostrará `[sms] skipped`.
